# 📝 Python To-Do List Application

A console-based To-Do List application written in Python, developed using **Object-Oriented Programming (OOP)** principles and **CSV file handling** for data persistence.

--

## ✨ Features
* **Object-Oriented Design:** Structured with dedicated classes for `Task` and `ToDoList`.
* **Task Management:** Easily add, delete, and view tasks.
* **Priority Levels:** Assign priority levels (High, Medium, Low) to each task.
* **Data Persistence:** Automatically save and load tasks using a `CSV` file.
* **Interactive Menu:** Simple and user-friendly command-line interface.


## 🚀 How to Use
1. Make sure Python is installed on your system.
2. Download or copy the project files into a folder on your computer and run the main program.


## 🛠️ Built With
* Python 3.x
* Object-Oriented Programming (OOP)
* Built-in CSV Module
